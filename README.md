## Project Description

This project explores the DataCo Supply Chain dataset to identify and compare two possible lines of analysis.

The two candidates considered are:

- **Candidate A - Sales Analysis:** Analysis of sales differences across regions and product categories.
- **Candidate B - Logistics Analysis:** Analysis of late delivery risk across regions, product categories, and shipping modes.

After the initial exploration and comparison, Candidate A was provisionally selected for further analysis.

Dataset used for the analysis. It contains information related to sales, customers, products, orders, regions, shipping, and delivery performance.

## How to Run the Analysis

1. Download or extract the complete project folder.
2. Open `analysis/Workshop_Inicio_Proyecto.ipynb`.
3. Make sure the dataset is available inside the `data/` folder.
4. Run the notebook cells from top to bottom.
5. Review the generated tables, charts, and interpretations.
